Title: Does Your Agent Know "Why"? - David Mihal

David Mihal argues agents need the reasons behind a codebase, not just the code, and shows how Meridian gives them those reasons with architecture decision records (ADRs).

Main Takeaways

- Meridian spent its first month writing only markdown specs, no code.
- With solid specs, the LLM becomes a compiler from English to Rust.
- 212 ADRs since March, about one a day. Some take longer than the code.
- A bad symbol prefix became a permanent ADR, so agents know why odd code exists.
- Setup is an ADR folder, one line in AGENTS.md, and comments citing "ADR 157".
