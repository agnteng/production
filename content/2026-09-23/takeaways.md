# Main takeaways

What someone would say they learned at this meetup, from its talks and Q&A.
One per line: `- **Claim.** One or two sentences.`

- **Many small bots beat one assistant.** Give each job its own bot (news briefings, brand mentions, prospecting), then put several in one chat to work as a team.
- **Tell the agent what done looks like.** Evaluation matters more than the model: an agent with a clear definition of done can keep looping until it gets there.
- **Long autonomous runs need supervision built in.** A coordinating agent that checks every pull request, and a heartbeat that notices when an agent has stopped, kept five agents productive for 30 hours.
- **Automate what already works.** That 30-hour run rested on seven weeks of building first. Get the product working, then automate the workflow you know.
- **Removing names doesn't protect anyone.** A few details, like a family of five that arrived in March, are enough to identify someone among thousands, and every session with a model adds another.
- **Collect fields, not stories.** Keep sensitive detail out of prompts and the model's files. If a device is seized, the session logs show exactly who was spoken to.
