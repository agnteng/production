### [Why AI Agents Ignore Your Design System: Nokia’s Fix](https://www.youtube.com/watch?v=_T7etJSiCfc)

Joel D'Silva walks through the four systems Nokia's design team built to keep coding agents inside an enterprise design system.

**Main Takeaways**

*   The context was always in the repo. Agents needed blinders, not more context
*   Their custom CLI search lost A/B tests once Cursor got better at searching
*   Validation scripts feed violations back into the agent loop, so no raw hex survives
*   Stuck points get logged to searchable JSON, not markdown, to make fixes more deterministic
*   His Figma plugin cuts a screen's context from 17,000 tokens to roughly 1,400
