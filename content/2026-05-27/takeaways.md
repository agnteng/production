# Main takeaways

What someone would say they learned at this meetup, from its talks and Q&A.
One per line: `- **Claim.** One or two sentences.`

- **Memory doesn't make an agent; orchestration does.** A model that remembers its session is still a function call. An agent keeps running, decides what to do next and coordinates its own work.
- **Give agents simple tools and let them build the rest.** You can't hand-write every tool an agent will need. Plain shell access and the freedom to write its own tools go further than a long list of integrations.
- **An agent will never tell you no.** It will open the pull request and write the 3,000 lines. The checks have to come from you: your own review, guards in the repo, and limits on what its credentials can reach.
- **Contribute with an agent the way a person would.** One idea per pull request, polish before you publish, and reply to maintainers yourself.
- **Voice agents are cheap enough for real errands.** Booking a restaurant table by phone costs under 20 cents a call, and the agent gets better by reading its own call transcripts.
