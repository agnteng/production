### [AI Agent Books a Table by Phone: ElevenLabs + Twilio](https://www.youtube.com/watch?v=3UYQt4oaKzw)

Sebastien Couture demos a Claude Code skill that phones a restaurant and books a table live, using ElevenLabs' conversational agent and a Twilio number.

**Main Takeaways**

*   A Claude skill calls the ElevenLabs conversational API, which dials out through Twilio
*   Offered 8:15, it held out for the 7 to 8pm window and got 7:15
*   The voice agent only gets what the call needs: instructions, name, phone number
*   Under 20 cents a call. Twilio costs most, about 7 cents a minute
*   Claude reads each transcript, fixes its call instructions, and sometimes calls back
