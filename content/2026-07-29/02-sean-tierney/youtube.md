Title: I Replaced OpenClaw With Claude Code - Sean Tierney

Sean Tierney demos behalf.bot, the open-source agent he built on Claude Code to ship software, run life admin and screen his dates.

Main Takeaways

- A month on OpenClaw never produced reliable work, so Claude Code became the harness.
- He briefs it by Loom; on stage it named Step Brothers and Bird by Bird.
- The dating bot drives an Android emulator, writes openers, learns his type, books coffee dates.
- That week: an insurance roof claim, HOA negotiations and a partner buyout.
- It runs on a fixed $100 a month Claude subscription, or OpenCode with open-weight models.
